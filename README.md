Getting Started

NexaCare is a comprehensive developer toolkit designed to accelerate the development of cross-platform Flutter applications, especially in healthcare and emergency response systems.

This project provides:
	•	Multi-platform support (Android, iOS, Web, Desktop)
	•	Real-time communication modules
	•	Modular and scalable architecture
	•	Firebase authentication & messaging integration
	•	High-quality tooling and project structure

Overview

NexaCare aims to simplify the creation of efficient, scalable, and user-friendly applications for emergency response workflows.

Core features include:
	•	🔥 Firebase integration
	•	🚀 Real-time communication (chat, notifications, tracking)
	•	🧩 Modular architecture
	•	🛠 Multi-platform Flutter setup
	•	📦 Reusable components & utilities
Installation

Clone the repository:
git clone https://github.com/BaviskarMahesh/NexaCare

Navigate to the project directory:
cd NexaCare

Install dependencies:
flutter pub get

Usage

Run the project:
flutter run
